GOOD TO KNOW

Questions, answered.

Are PDFWay tools free? +

Core browser tools are free to use. Some advanced features may depend on processing support and will be clearly marked.

Are my files uploaded? +

Supported local tools work in your browser and don't send files to a server. This demo site has no backend upload service.

Can I sign in with Google or email OTP? +

Account interface is prepared, but secure account sign-in requires connecting a Supabase project and configuring OAuth/OTP settings.
